# 第一批模板清单

## 1. 文档目的

本文档用于固定第一批建议内置的模板清单，作为以下内容的直接依据：

- 属性管理页中的模板视图展示
- 从模板创建属性时的默认配置
- 从模板创建规则时的默认配置
- 后续代码实现时的模板常量、模板详情页与创建流程

本文档不负责解释模板体系的总体规则。

## 2. 当前清单范围

第一阶段模板清单分为两部分：

1. 第一批属性模板
2. 第一批规则模板

其中：

- 属性模板先以“价格家族”作为第一批基石模板重点
- 规则模板先以“总价、平均价值、待付尾款、订阅相关”作为第一批重点

---

## 3. 第一批属性模板

## 3.1 基础属性模板

第一阶段建议内置以下基础属性模板：

1. 文本模板
2. 数值模板
3. 日期模板
4. 布尔模板
5. 输入型多值模板
6. 固定选项模板
7. 固定选项多选模板

这些模板的目标是：

- 覆盖最常见的通用字段创建场景
- 让“从零创建属性”本质上仍然是从标准模板创建

## 3.2 价格家族属性模板

第一阶段建议优先建设以下价格家族属性模板：

1. 购入价格属性模板
2. 总价属性模板
3. 当前估值属性模板
4. 定金属性模板
5. 订阅价格属性模板
6. 自定义价格属性模板

原因是：

1. 价格是当前最复杂、最容易失控、也最值得模板化的字段类型。
2. 价格和规则模型之间的结合最紧密。
3. 价格家族先跑通后，后续再扩展到日期、面积、重量等属性模板会更稳。

---

## 4. 属性模板统一字段

为了保证属性模板表达一致，以下每个属性模板都按同一套字段描述：

1. 模板标识
2. 模板名称
3. 模板分类
4. 默认属性名
5. 默认值类型
6. 默认选项来源
7. 默认输入方式 / 选择方式
8. 默认多选开关
9. 默认图标
10. 默认规则绑定
11. 可编辑边界
12. 典型用途

## 7. 第一阶段实现建议

## 7.1 模板详情页建议展示内容

第一阶段模板详情页建议展示：

- 模板名称与图标
- 模板分类
- 模板说明
- 默认定义或默认输入角色
- 默认规则绑定或默认输出定义
- 典型用途
- `从模板创建属性` 或 `从模板创建规则` 按钮

## 7.2 第一阶段不做

为了控制复杂度，第一阶段暂不做：

- 用户自定义新属性模板结构
- 用户自定义新规则模板结构
- 模板级别的公式编辑器
- 模板级别的规则可视化编排器

---

## 8. 最终固定方案

当前第一批模板清单可固定如下：

1. 第一阶段模板清单应同时包含属性模板与规则模板。
2. 第一批属性模板先严格收敛为：
   - 基础属性模板
   - 价格家族属性模板
3. 第一批规则模板先严格收敛为：
   - 计入总价
   - 平均价值
   - 待付尾款
   - 周期扣费
   - 订阅已支付
4. 属性模板负责定义字段默认值与默认规则绑定，规则模板负责定义输入角色、默认逻辑与输出形态。
5. 第一阶段先把价格家族属性模板和对应规则模板家族跑通，再扩展到其他属性领域。

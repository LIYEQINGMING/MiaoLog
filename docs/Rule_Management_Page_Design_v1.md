# 规则管理页设计文档 v1

## 1. 文档定位

本文档用于落地“属性管理页面中的规则视图”，作为规则相关页面的总入口设计稿。

本文档重点回答：

- 规则管理列表页在当前版本中到底管理什么
- 列表页展示哪些信息，才能和新的规则模型保持一致
- 列表页与“画布式规则编辑器”如何对齐

---

## 2. 页面定位

规则管理页是“规则治理入口”，不是规则运行页。

它负责：

- 浏览全部规则定义
- 搜索规则
- 按来源、启用能力、调度能力、使用情况筛选
- 查看规则的用户开关控制摘要
- 查看规则的调度摘要
- 进入规则详情页
- 创建自定义规则
- 编辑自定义规则
- 删除自定义规则

它不负责：

- 在列表页直接做复杂槽位编辑
- 在列表页直接完成属性绑定
- 在列表页直接运行或调试规则
- 展示完整画布结构编辑

固定原则：

- `列表页负责发现规则`
- `详情页负责理解规则`
- `编辑页负责定义规则`
- `物品页负责绑定规则实例`

---

## 3. 核心设计原则

### 3.1 列表对象是“规则定义”

规则管理页中的每一项都代表一条“规则定义”，不是规则绑定实例。

因此列表页展示重点应是：

- 规则名称
- 规则说明
- 槽位与输出摘要
- 用户开关控制摘要
- 周期调度摘要
- 被多少物品规则实例使用
- 是否允许编辑与删除

### 3.2 不再以“规则类型”作为主视角

当前正式结论：

- “规则类型”不再是规则编辑页核心概念
- 因此规则管理页也不应再过度依赖旧的 `求和 / 差值 / 平均值 / 周期 / 自定义` 分类

第一阶段建议：

- 列表中不再强调旧规则类型标签
- 若数据层仍保留该字段，仅作为兼容或内部归档使用

真正对用户更有价值的标签是：

- 是否允许用户开关控制
- 是否包含周期调度
- 是否为系统规则

### 3.3 列表页要能看见“影响范围”

规则管理的核心不是只看规则名，而是看：

- 这条规则目前是否被使用
- 被多少物品规则实例引用
- 删除后影响多大范围

---

## 4. 页面结构

规则管理页建议稳定为以下结构：

1. 页面头部
2. 搜索框
3. 筛选区
4. 规则列表区
5. 主操作入口

推荐结构：

```text
属性管理
- Tab：属性 / 规则 / 模板
- 搜索框
- 规则筛选区
- 规则列表
- 新建规则
```

---

## 5. 搜索与筛选

### 5.1 搜索行为

搜索应支持以下命中维度：

- 规则名称
- 规则说明
- 槽位 key 或槽位名称
- 输出槽位名称
- 开关文案
- 调度说明

### 5.2 筛选维度

第一阶段固定四类筛选：

1. 来源筛选
   - 全部来源
   - 系统规则
   - 自定义规则
2. 用户开关控制筛选
   - 全部
   - 可用户控制
   - 默认始终启用
3. 调度能力筛选
   - 全部
   - 含周期调度
   - 不含周期调度
4. 使用情况筛选
   - 全部
   - 已被使用
   - 未被使用

---

## 6. 列表卡片设计

### 6.1 每张卡片建议展示的信息

每个规则卡片建议展示：

- 规则名称
- 来源标签
- 槽位摘要
- 输出摘要
- 用户开关控制摘要
- 周期调度摘要
- 使用范围摘要

### 6.2 卡片示意

```text
周期扣费      [系统规则]
输入：购入价格 / 扣费周期 / 扣费日
输出：周期扣费金额 / 下次扣费日期
启用：用户可开关（自动续费 / 暂停续费）
调度：来自槽位或手动日历规则
影响：已被 6 个物品规则实例使用
```

### 6.3 信息优先级

规则卡片中的信息优先级固定如下：

1. 规则名称
2. 来源
3. 槽位摘要
4. 输出摘要
5. 启用控制摘要
6. 调度摘要
7. 影响范围摘要

---

## 7. 编辑入口与编辑页对齐

点击“新建规则”或“编辑规则”后，进入的应是新的规则定义编辑页。

该编辑页的正式方向已经固定为：

- 基本信息
- 用户开关控制
- 周期调度配置
- 可视化公式画布

不再是：

- 规则类型选择
- 变量管理大表单
- 表达式大文本框

因此规则管理页在文案和空状态引导上也应同步：

- 强调“通过画布定义规则”
- 而不是“填写规则类型并输入表达式”

---

## 8. 删除确认设计

删除规则前必须展示影响提示，不允许无提示直接删除。

删除确认弹窗至少需要说明：

- 规则名称
- 当前被多少物品规则实例使用
- 删除后会自动移除这些物品上的规则实例

---

## 9. 第一阶段固定边界

第一阶段建议完成：

1. 规则列表浏览
2. 搜索规则
3. 来源 / 用户开关控制 / 调度能力 / 使用情况筛选
4. 使用范围统计
5. 规则详情跳转
6. 规则创建入口
7. 规则编辑入口
8. 删除前影响提示

第一阶段暂不做：

- 列表页直接编辑画布
- 规则运行日志
- 规则调试台
- 规则版本对比

---

## 10. 最终结论

当前可固定的规则管理页方案如下：

1. 规则管理页是规则定义的治理入口，不是规则实例绑定页。
2. 列表对象是“规则定义”，不是规则绑定实例。
3. 列表页不再以旧规则类型作为主分类视角。
4. 页面必须展示槽位摘要、输出摘要、用户开关控制摘要和调度摘要。
5. 编辑入口要与新的“画布式规则编辑器”保持一致。

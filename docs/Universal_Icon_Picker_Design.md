# 系统级通用图标选择器设计文档 (Universal Icon Picker Design)

## 1. 文档目的
本文档旨在定义 MiaoLog 系统的通用图标选择器组件的设计方案。该组件将作为全局基础 UI 单元，统一支持分类、属性、标签、位置等多个模块的图标选择需求，提供类似于 Notion 的高度集成、易用的交互体验。

---

## 2. 设计目标
- **全系统一致性**：确保应用内所有涉及图标选择的场景（分类、属性、模板等）具有统一的交互逻辑和视觉表现。
- **多维度资源支持**：
  - **表情符号 (Emoji)**：支持全量 Unicode Emoji，按标准分类展示。
  - **图标库 (Icons)**：集成 Material Design 扩展图标库，支持搜索。
  - **自定义上传 (Upload)**：支持用户上传本地图片作为图标。
- **高效检索**：提供实时搜索、分类导航以及“最近使用”功能。
- **现代化 UI**：遵循系统的“液态玻璃 (Liquid Glass)”设计风格，支持沉浸式转场和弹簧动画。

---

## 3. 核心功能模块

### 3.1 导航与切换 (Navigation)
选择器顶部采用分段式切换（Tabs）：
- **表情符号**：展示系统 Emoji。
- **图标**：展示矢量图标库（Material Icons）。
- **上传**：提供图片上传入口。
- **移除**：快速清除当前已选图标。

### 3.2 检索与过滤 (Search & Filter)
- **实时搜索**：支持按名称搜索 Emoji 或图标。
- **分类导航**：在 Emoji 视图下提供侧边或底部的分类锚点导航（如：表情、食物、自然、活动等）。
- **随机/确认**：提供“随机选择”功能，增加趣味性；点击“确认”或“图标项”完成选择。

### 3.3 最近使用 (Recents)
- **位置逻辑**：集成在底部锚点导航的首位（🕒），点击可快速跳转至“最近使用”区块。
- **扩容存储**：记录用户最近选择的前 20 个图标/Emoji，确保用户的高频个性化选择能够被有效保留。
- **展示策略**：在所有 Tab 的列表顶部优先展示，且支持在“最近使用”区块内进行二次搜索。

## 5. 技术选型 (Technical Selection)

为了确保全系统的兼容性、原生感以及授权安全，采用以下技术栈：

### 5.1 表情符号：Google Noto Emoji
- **选型理由**：
  - **跨平台一致性**：作为 Android 系统的官方 Emoji 字体，Noto Color Emoji 在不同设备上具有高度的视觉统一性。
  - **免费商用**：采用 SIL Open Font License，完全开源且无版权风险。
  - **支持完备**：涵盖了最新的 Unicode Emoji 标准。

### 5.2 图标库：Google Material Symbols
- **选型理由**：
  - **原生升级**：它是 Material Icons 的最新演进版，风格更现代。
  - **动态参数**：支持自定义 Weight（粗细）、Fill（填充状态）、Grade（渐变）和 Optical Size（视觉大小），能够完美适配“液态玻璃”设计中的细微视觉调整。
  - **集成方便**：与 Jetpack Compose 深度集成，资源占用小。

## 6. 数据模型与复用 (Architecture)

### 5.1 数据模型 (Data Model)
使用密封类（Sealed Class）定义图标来源：
```kotlin
sealed class IconSource {
    data class Emoji(val code: String) : IconSource()
    data class Vector(val name: String) : IconSource()
    data class Custom(val uri: String) : IconSource()
    object None : IconSource()
}
```

### 5.2 组件复用规则
- **MiaoIconPicker**：作为纯 UI 组件，不持有业务逻辑。
- **入参**：
  - `initialIcon: IconSource`
  - `onIconSelected: (IconSource) -> Unit`
- **调用方**：
  - `CategoryManagement` -> 传递分类图标更新逻辑。
  - `AttributeManagement` -> 传递属性图标更新逻辑。
  - `ItemTemplateEditor` -> 传递模板图标更新逻辑。

## 7. 演进路线

### 第一阶段：基础 Emoji 资源重构
- 将 Emoji 资源按 Unicode 标准进行分门别类（人物、食物、自然等）。
- 实现 `MiaoIconPicker` 的基础布局与分类锚点导航。
- 在分类管理页进行首个场景的接入验证。

### 第二阶段：Material Symbols 集成与搜索
- 整合 Google Material Symbols 库。
- 实现全局搜索逻辑，支持跨 Tab 搜索 Emoji 和图标。
- 引入 `DataStore` 实现“最近使用”功能（20 个记录容量）。

### 第三阶段：自定义上传与 KMP 适配
- 支持图片上传与简单的裁剪/预览。
- 优化桌面端交互，将 Sheet 切换为 Popover 气泡菜单。

## 20260727 物品编辑页规则 Tab 公式化重构
### 本轮调整

- 针对物品编辑页的规则 Tab，开始把“规则配置区”从普通表单列表，收口成更接近可视化公式编辑器的呈现方式。
- 本轮目标主要围绕 3 件事：
  - 修正已有规则在编辑页中的默认载入体验
  - 让规则卡把“规则 + 绑定属性 + 公式 + 开关 + 输出预览”收拢成一组
  - 移除用户不需要关心的默认触发信息

### 已有规则载入

- 修正了 `EditItemViewModel` 中编辑页规则实例的加载顺序：
  - 先读取数据库中已存在的物品规则实例
  - 再在需要时补系统建议规则
- 这样可以避免“数据库已有规则被自动补规则覆盖”或“自动补规则先出现，随后又被空列表覆盖”的情况。

### 规则卡结构

- 重构了 `ItemRuleBindingSection` / `ItemRuleBindingCard`：
  - 卡片顶部保留规则名、描述、缺失槽位提醒、删除操作
  - 中间新增“已绑定属性”汇总，直接展示这条规则当前实际关联了哪些属性
  - 新增“公式预览”区域，用 `输入 -> 输出` 的方式把规则结构直接展示出来
  - 保留原始表达式文本作为辅助信息，方便后续继续增强成更完整的公式编辑器

### 开关与槽位

- 对 `USER_TOGGLE` 规则，卡片内新增了显式“运行开关”分组：
  - 展示当前启停文案
  - 展示与锚点属性关联的说明
  - 直接在规则卡内切换启停
- 后续继续收口后，规则卡不再把“输入区 / 输出区 / 预览区”拆成多段，而是转为公式槽位式编辑。

### 输出预览

- 原先规则页中“规则列表”和“只读输出预览”是分离的，现在改为：
  - 每条规则自己的输出，直接显示在它自己的规则卡下面
- 这样用户在看某条规则时，可以直接看到：
  - 这条规则绑定了什么
  - 公式长什么样
  - 现在能算出什么结果

### 精简展示

- 去掉了 `ON_VALUE_CHANGED / ON_SAVE` 这类默认触发方式展示。
- 这些是系统默认运行机制，不再占用规则卡的主要认知空间。

### 继续收口

- 根据后续交互反馈，规则卡继续向“公式槽位编辑器”推进：
  - 规则卡从上到下收敛为：
    - 规则名称 + 描述
    - 已绑定属性
    - 计算公式
    - 运行开关
  - 公式中的变量改为槽位形式展示，可直接点击槽位替换属性绑定
  - 必填但未绑定的属性槽位改为浅红边框提示
  - 系统变量槽位改为灰色不可调整
- 属性页也开始承接规则开关回流：
  - 当某条规则配置了 `USER_TOGGLE` 且锚定到了某个属性
  - 该属性在属性 Tab 下方会直接显示对应的业务开关
  - 第一批已覆盖数量与补充属性项，方便把“规则开关”回投到用户最熟悉的属性录入界面

### 备注

- 本轮没有本地编译，继续由你本机验证。
- 当前这版已经把规则页往“公式 + 槽位 + 输出”的方向推进了一步，下一步如果需要，可以继续把公式区域强化成更接近解码器/节点流的可视化表达。

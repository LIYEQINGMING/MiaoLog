## 20260723 物品页前端收口

### 本轮调整

- 新建页、编辑页继续沿用 `属性 / 规则` 双页签，不再在属性页保留旧的“功能区”展示，避免和规则页职责重叠。
- 物品名称、分类、顶部标题、页签、保存按钮、删除确认等当前可见的关键文案已恢复为正常中文，先把主流程可用性拉回稳定状态。
- 规则相关的只读输出预览继续放在规则页，属性页只负责属性录入与补充属性管理。

### 设计落点

- 属性页负责“这个物品有哪些属性”。
- 规则页负责“这个物品用了哪些规则，以及规则槽位绑定了哪些属性”。
- 规则输出仍然通过物品级规则实例回写，不再把旧的功能区当作独立编辑入口。

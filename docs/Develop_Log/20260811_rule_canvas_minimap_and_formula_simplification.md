## 20260811 规则画布导航、动态扩张与公式编码精简

## 修改建议

- 普通规则页中的画布预览窗口继续保持 9:16，但预览窗口背后的实际逻辑画布需要更大；节点超出现有逻辑边界时，画布应自动扩张，而不是限制节点继续移动。
- 在预览窗口左下角的聚焦按钮上方增加画布缩略导航图，显示节点分布和当前可视范围，并提供视窗放大、缩小和快速定位能力。
- 缩小画布节点，减少复杂公式在手机视窗中的占用，让更多节点关系能够同时被观察。
- 槽位不再分别维护“变量标识”和“变量名称”两套用户可见名称；画布节点和公式编码统一使用同一个变量名称，避免可视化表达与文本表达割裂。
- 公式编码区域只保留可直接编辑的公式输入框，移除快捷片段、变量引用、函数片段、规则预设和公式解码等辅助区域，规则编辑以可视化画布为主。

## 实现结果

- 已扩大并支持动态扩张实际画布：
  - 默认逻辑画布由 `1600 x 1000` 扩大为 `2400 x 1600`。
  - 节点拖动到当前右侧或底部边界之外时，节点实时范围会参与画布尺寸计算，实际画布自动扩张。
  - 为避免无限坐标导致绘制和持久化异常，逻辑画布设置 `6000 x 4000` 的安全上限。

- 已增加缩略导航图和缩放控制：
  - 普通预览模式下，在左下角聚焦按钮上方展示实际画布、节点缩略分布和当前视窗框。
  - 点击缩略图中的位置可以将预览视窗中心移动到对应逻辑坐标。
  - 缩略图下方提供放大和缩小按钮，缩放时保持当前视窗中心对应的逻辑位置不变。
  - 画布缩放范围调整为 `15% - 200%`，方便在完整布局总览和局部精细编辑之间切换。

- 已缩小画布节点：
  - 节点统一高度由 `84dp` 调整为 `64dp`。
  - 槽位、运算符、函数和字面量节点宽度分别缩小为 `104dp`、`52dp`、`88dp` 和 `80dp`。
  - 同步缩小节点内边距、标题字号和运算符字号，保留输入、输出及待配置状态的视觉区分。

- 已统一槽位变量名称：
  - 槽位配置弹窗只保留“变量名称”一个字段。
  - 保存时同一个规范名称同时作为槽位引用键和显示名称，画布节点与公式编码显示一致。
  - 新建槽位使用 `属性输入1`、`结果变量1` 等可直接阅读和编码的默认名称。
  - 槽位改名会同步更新运行开关锚点和调度槽位引用；内部稳定身份继续由不可见的槽位 ID 维护。
  - 旧规则继续使用已有引用键，不做破坏现有公式的强制迁移。

- 已精简公式编码区域：
  - 页面只保留“公式编码”输入框，可直接修改表达式并反向更新可视化节点。
  - 可视化节点调整后仍会按照空间顺序更新公式编码。
  - 快捷片段、变量引用、函数片段、规则预设和公式解码不再出现在规则新建或编辑页面。
  - 底层词法解析继续用于公式编码到画布的双向同步，不作为独立解码功能展示。

## 20260731 规则管理页独立与规则编辑页结构重排
### 本轮调整

- 按最新确认方向，把“规则管理”从原来的“属性管理”复合页中独立出来，升级为和“分类管理”“属性管理”同级的一级页面入口。
- 独立后的规则管理页，不再以“属性 / 规则 / 模板”三 Tab 组织，而是直接以规则定义治理为唯一主视角：
  - 规则列表
  - 搜索与筛选
  - 新建规则
  - 规则详情 / 编辑
- 同时把规则编辑页的主结构继续往新方案推进，从旧的“变量管理 + 文本表达式”进一步收口为：
  - 画布素材
  - 公式画布
  - 槽位配置
  - 保存

### 页面入口与导航

- 新增 `RuleManagementFragment`，与原 `AttributeFragment` 平级。
- `Profile` 页菜单新增：
  - `规则管理`
- Navigation 图新增：
  - `action_profile_to_rule_management`
  - `nav_rule_management`

### 页面模式收口

- `AttributeManagementUiState` 新增 `entryMode`，用于区分：
  - `ATTRIBUTES`
  - `RULES`
- `AttributeManagementViewModel` 新增 `initializeEntryMode()`：
  - 属性管理入口默认锁定到属性视图
  - 规则管理入口默认锁定到规则视图
- 这样一来，虽然底层仍复用同一套 ViewModel / 数据源，但页面入口在体验上已经正式拆开。

### 属性管理页

- 现在属性管理页进入后只展示：
  - 属性列表
  - 属性筛选
  - 新建属性
- 不再向用户暴露：
  - 规则 Tab
  - 模板 Tab

### 规则管理页

- 现在规则管理页进入后只展示：
  - 规则列表
  - 规则筛选
  - 新建规则
- 搜索提示语同步改成围绕规则：
  - 规则
  - 槽位
  - 调度配置

### 规则编辑页

- 去掉了旧的“规则类型”可视化入口后，保存时统一按：
  - `RuleComputationType.CUSTOM`
  写回，旧字段只保留兼容语义。
- 规则编辑页结构已继续重排：
  - `画布素材`
    - 空输入槽位
    - 空输出槽位
    - 系统变量槽位
    - 固定值槽位
  - `公式画布`
    - 用节点卡片可视化展示当前槽位
    - 通过颜色与标签区分输入 / 输出 / 系统 / 固定值 / 待完善
  - `槽位配置`
    - 将旧的变量卡片收口为“槽位配置”面板
- 保存时会同步生成一份基础 `canvasDefinition`，把当前槽位结构映射为画布节点和顺序连接，作为后续完整拖拽画布的正式底稿。

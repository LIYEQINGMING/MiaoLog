## 20260727 物品页顶部栏沉浸式统一
### 本轮调整

- 统一了新增物品页和编辑物品页的 Compose 顶部栏结构，两页都改成“返回按钮 + 标题区 + Tab”的同一套视觉层级；新增页保留模板切换入口，编辑页保留撤销与删除入口。
- `MainActivity` 对 `addItemFragment / editItemFragment` 不再显示 Activity 顶部栏，同时把这两个页面加入“由 Fragment 自己处理状态栏 inset”的名单，避免容器和 Compose 表单重复给顶部留白。
- `ItemFormScaffold` 的状态栏下方顶部间距从 `8dp` 收紧到 `2dp`，让返回按钮在视觉上更贴近状态栏下沿，符合沉浸式表单页的预期。
- `AddItemFragment` 改成和编辑页一致的 `hideActionBar()/showActionBar()` 管理方式，并把新增页返回操作收回到 Compose 顶部栏处理，去掉对旧 `ActionBar` 返回按钮的依赖。
- 顺手修正了新增页/编辑页顶部、Tab、物品名称、分类、规则提示等本轮直接暴露给用户的关键文案乱码，并把新增页默认初始字段保持为“名称 / 分类 / 数量”，不再默认附带“状态 / 标签”。

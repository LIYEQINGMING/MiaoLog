## 20260814 规则画布操作数模型、工具栏与节点插入优化

## 修改建议

- 公式编辑器不再在素材层区分输入槽位、输出槽位、系统变量和固定值，这些对象本质上都是参与公式的操作数，差异应在节点配置中表达。
- 素材栏只保留统一的“操作数”入口；函数继续作为独立素材，并新增 `()`、`{}`、`[]` 等分组符节点。
- 聚焦、缩放导航和全屏入口集中到画布底部居中的悬浮工具栏，缩略导航图和放大缩小控制仅在点击放大镜后展开。
- 当节点被拖入两个相邻节点之间时，应形成真正的公式顺序插入，并自动为右侧相邻节点链让出空间。
- 直接编辑公式编码时，普通变量标识符应自动生成可配置的操作数节点，文本顺序变化也应同步重排画布。
- 全屏画布继续与 App 屏幕方向隔离，但内部编辑区域需要使用完整设备宽屏尺寸，工具栏保持底部居中。

## 实现结果

- 已统一画布操作数模型：
  - UI 画布节点类型由 `SLOT` 调整为 `OPERAND`。
  - 素材栏不再提供输入、输出、系统变量和固定值四种槽位，只提供一个“操作数”。
  - 点击素材栏“操作数”会直接向画布加入默认操作数节点，不自动打断操作并打开弹窗。
  - 再次点击画布中的操作数节点时打开“操作数配置”，集中配置操作数名称、节点方向、值来源和说明。
  - 底层继续复用已有规则槽位草稿和 `RuleCanvasNodeType.SLOT` 持久化格式，兼容已有规则，无需数据库迁移。

- 已新增分组符素材和节点：
  - 素材栏新增“分组符”分类，提供 `()`、`{}`、`[]`。
  - 分组符在画布中使用独立 `GROUPING` 节点类型和紧凑尺寸。
  - 公式解析会把分组符恢复为对应画布节点；保存时兼容映射为原有运算符节点。
  - 函数仍保持独立素材，加入函数时自动附带左右圆括号分组节点。

- 已重构画布底部工具栏：
  - 聚焦、缩放导航和全屏入口集中到画布底部居中的圆角悬浮工具栏。
  - 工具栏使用紧凑的 macOS Dock 式外观，不铺满整个画布底部。
  - 点击放大镜后，在工具栏上方展开实际画布缩略图、当前视窗框、缩小、倍率和放大控制。
  - 普通预览和全屏画布共用同一套底部工具栏；切换全屏时自动收起缩放导航面板。

- 已实现节点链插入：
  - 磁吸结果现在可以同时标记相邻的左右节点和插入目标。
  - 节点拖到两个相邻节点的间隙时，会吸附到左节点之后。
  - 松手后，右节点及其同一行连续节点链整体右移，为插入节点让出完整宽度。
  - 未命中相邻节点间隙时仍使用原有四向边缘磁吸和自由布局，不强制整行重排。

- 已完善公式编码反向编辑：
  - 直接输入 `B` 等普通变量名时，自动创建同名操作数定义并生成可配置的操作数节点。
  - 函数名后跟左括号时继续识别为函数，不会误建为操作数。
  - 连续输入变量名时以当前公式引用集合为准，不会遗留 `B / Bi / Bil` 等中间操作数。
  - 公式文本顺序变化会按新表达式重新布局节点，`B + C` 改为 `C + B` 后画布顺序同步变化。
  - 删除重复引用中的一个操作数节点时，仅在最后一个引用被删除后移除操作数定义。

- 已修正全屏宽屏约束：
  - 全屏 Dialog 继续只旋转内部画布，不修改 Activity 或 App 屏幕方向。
  - 横向画布使用 `requiredSize` 获取交换后的完整设备宽高，避免被竖屏父约束压缩。
  - 全屏工具栏保持在宽屏画布底部居中，系统返回、左上角返回和工具栏退出全屏仍返回竖屏规则页。

## 20260806 规则画布素材栏横向化与工具区收口

## 修改建议

- 规则公式编辑器中的素材栏不再使用左侧纵向长列表，改为更贴近画布编辑器习惯的横向分类入口。
- 分类入口用图标表达，例如：
  - 槽位
  - 算术运算
  - 比较运算
  - 逻辑运算
  - 函数
- 点击分类图标后，在下方展开一行可左右滑动的具体素材，减少对画布可视空间的长期占用。
- 原“画布工具箱”的职责需要重新梳理：
  - 与画布节点直接相关的“加槽位 / 加运算符 / 加函数”等动作，应并入素材栏与画布主区域
  - 与手动文本表达式相关的快捷片段，应留在“公式编码（高级）”附近，避免概念混杂
- 规则编辑页主路径要继续强化“先选素材，再落到画布，再补槽位配置”的使用节奏。

## 实现结果

- 已将规则画布素材栏改为“横向图标分类 + 下方横向滑动素材条”的结构。
- 当前已接入的分类包括：
  - 槽位
  - 算术运算
  - 比较运算
  - 逻辑运算
  - 函数
- 分类图标采用 Material Icons，点击后可展开或收起该分类对应的素材条。
- 素材条中的项目改为卡片式横向展示，点击后直接向画布添加对应节点：
  - 空槽位
  - 运算符
  - 函数
- 原独立的“画布工具箱”区块已从规则编辑主视图中移除，并完成职责收口：
  - 节点类操作统一并入“公式画布”卡片顶部的素材栏
  - 文本片段辅助保留在“公式编码（高级）”区域
- “公式画布”区域同步改为纵向结构：
  - 顶部为素材栏
  - 下方为实际拖拽画布
  这样更适合后续继续扩展横向素材分类与更大的画布交互区。
- 页面文案同步调整为以“点击素材栏图标展开分类，并将节点加入画布”为主，降低旧“工具箱”概念带来的理解负担。

## 备注

- 本轮主要是规则编辑器交互骨架的调整，真正的“公式拖拽编排体验”仍需继续深化：
  - 节点拖拽布局
  - 槽位配置提示
  - 节点连接与解析反馈
- 本轮未在本地完成最终编译验证，继续由项目环境联调确认。

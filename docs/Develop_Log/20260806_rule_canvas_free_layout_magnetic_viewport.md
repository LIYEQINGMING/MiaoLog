## 20260806 规则画布自由布局、节点磁吸与横屏全屏修正

## 修改建议

- 规则管理页面仍出现两层“返回键 + 规则管理”页头，需要确认宿主 Activity 顶栏与 Compose 自定义页头的显示职责，规则管理应与分类管理、属性管理保持一致，只显示 Compose 自适应页头。
- 公式编辑器的磁吸关系应发生在节点与节点之间，而不是节点与画布边缘或固定网格之间。
- 节点需要能够在完整逻辑画布中自由排布，手机普通页面只展示画布的一部分，不应将完整画布强行压缩到当前可见区域。
- 普通模式应作为画布预览视窗，允许平移和缩放查看；全屏模式应旋转为横屏，提供更大的公式编辑空间。
- 可视化节点与公式编码继续保持双向联动，节点自由排布后按照“从左到右、从上到下”的空间顺序编译。

## 实现结果

- 已修复规则管理重复页头：
  - 将 `nav_rule_management` 加入 `MainActivity` 的自定义页面顶栏隐藏范围。
  - 同步补齐首次恢复页面、导航切换、底部导航显示和所属主导航分组的处理。
  - 规则管理现在与分类管理、属性管理一致，只保留 Compose 自适应页头。

- 已将规则画布从固定顺序网格重构为自由坐标画布：
  - 节点保留各自的绝对坐标，可在 1600 × 1000 的逻辑画布中自由移动。
  - 节点移动时只做画布范围约束，不再吸附画布边缘，也不再自动回到固定网格。
  - 新加入的节点会在已有节点之后获得初始位置，之后可由用户自由调整。

- 已实现节点与节点之间的边缘磁吸：
  - 当节点靠近另一个节点的左、右、上、下边缘时，自动吸附到相邻位置。
  - 磁吸过程中目标节点会显示高亮边框，作为当前吸附对象的视觉反馈。
  - 未进入磁吸阈值时，节点保持自由移动状态。

- 已实现画布预览视窗：
  - 普通规则编辑页中的画布区域调整为固定高度预览视窗。
  - 逻辑画布尺寸不再受手机当前可见区域限制。
  - 支持拖动画布、双指缩放和重置视窗，视窗状态在普通模式与全屏模式之间共享。

- 已实现横屏全屏编辑：
  - 点击画布右下角全屏按钮后，请求进入横屏方向。
  - 全屏视图使用完整可用空间展示素材栏与画布。
  - 退出全屏后恢复进入前的屏幕方向。
  - `MainActivity` 增加方向和屏幕尺寸配置变更处理，避免横竖屏切换时重建并丢失未保存的画布状态。

- 已完善自由画布与公式编码的联动：
  - 公式生成顺序改为根据节点空间位置按行解析，同一行从左到右，不同行从上到下。
  - 节点自由坐标写入规则画布定义，画布定义版本升级为 `2`。
  - 再次打开规则时优先恢复已保存的节点坐标；旧版本没有自由坐标的数据会自动使用默认顺序布局。

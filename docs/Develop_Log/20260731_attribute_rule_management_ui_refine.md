## 20260731 属性管理收口与规则画布编辑强化
### 本轮调整

- 按今天确认的新方向，继续收口“属性管理 / 规则管理”的页面结构，重点处理三件事：
  - 管理页顶部栏统一到“分类管理”的视觉样式
  - 属性管理彻底去模板化、补上属性编辑与复制能力
  - 新建规则页从“长表单”继续推进到“画布主导 + 当前槽位配置”的编辑体验

### 顶部栏统一

- `属性管理` 与 `规则管理` 的列表页顶部栏已统一成与 `分类管理` 同一套结构：
  - 更贴近状态栏的顶部间距
  - 左返回 / 中标题 / 右新增
  - 同款搜索输入框
- 二级页头也同步改成同系列玻璃卡片样式，视觉上不再和一级页割裂。

### 属性管理页

- 属性列表卡片继续精简：
  - 去掉左侧圆形图标
  - 保留名称、来源、值类型、值来源、值属性摘要
- 属性项右侧菜单新增：
  - `编辑属性`
  - `复制属性`
  - `删除属性`
- 复制属性已接通真实数据流：
  - 复制后会生成新的属性 id / key
  - 名称自动按“副本 / 副本 2 ...”去重
- 编辑已有属性时，当前只允许修改：
  - 属性名称
  - 属性说明
- 值类型、值来源和值属性改为只读展示，不再允许误改结构定义。

### 属性详情页

- 去掉了 `来源模板` 展示。
- 详情页内容压缩为：
  - 属性摘要
  - 属性定义
  - 操作
- “属性定义”改成更舒展的文本块样式，减少之前重复和拥挤的问题。

### 模板相关收口

- 属性管理列表页与规则管理列表页的空态 / 搜索态文案已去掉“从模板创建”的旧提示。
- 新建属性页 / 新建规则页的摘要和按钮文案也同步移除了模板导向描述。
- 本轮仍保留底层模板数据结构兼容代码，但不再继续强化模板管理入口体验。

### 规则创建页

- 新建规则页继续从“表格式槽位管理”向“画布式公式编辑”推进：
  - `画布工具箱`
  - `公式画布`
  - `当前槽位配置`
  - `公式编码`
- 当前画布改成三段式展示：
  - 输入槽位区
  - 公式编码层
  - 输出槽位区
- 槽位支持通过颜色与标签区分：
  - 待完善
  - 外部输入
  - 系统变量
  - 固定值
  - 输出
- 点击槽位后，不再展开整页一长串槽位表单，而是只编辑“当前选中槽位”，明显降低表格感。

### 兼容与修正

- 规则画布保存仍会继续生成 `canvasDefinition`，保持与前面已经落下的数据结构兼容。
- 顺手修正了一处规则画布 helper 的括号层级问题，并把系统变量 key 的解析收口到 `findSystemVariableKey(...)`，避免旧引用继续引发编译问题。

### 备注

- 本轮没有在本地执行编译，继续由你本机验证。
- 下一步如果继续深挖规则管理，重点就会放在：
  - 真正的拖拽式画布交互
  - 槽位创建弹窗
  - 规则管理页与物品页规则实例之间的配置映射

### 补充修正

- 进一步把 `AttributeManagementScreen` 的模板入口参数从界面调用链中移除：
  - `AttributeFragment`
  - `RuleManagementFragment`
  - `AttributeManagementScreen`
- 模板详情路由改为停用提示页，避免再通过旧入口进入模板管理体验。
- 规则画布补上了 `公式轨道`：
  - 公式现在会被拆成变量块、函数块、字面量块、符号块、待修正块
  - 以横向轨道方式直接展示在输入槽位和输出槽位之间
- 快捷片段也已前移到 `画布工具箱`，让规则编辑主路径更像画布拼装而不是线性表单填写。
